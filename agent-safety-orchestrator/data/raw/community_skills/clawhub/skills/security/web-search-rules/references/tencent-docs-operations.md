# 騰訊文檔操作參考

## 知識庫管理

### 檢查知識庫是否存在

使用 `tencent-docs` skill 列出所有文檔，檢查目標知識庫是否存在。

### 創建知識庫

如果知識庫不存在，使用 `tencent-docs` skill 創建：

```
知識庫名稱：搜索網址庫
描述：記錄搜尋規則、網址的暫存名單（未分類白名單還是黑名單）、白名單和黑名單

知識庫名稱：未整理搜尋內容
描述：暫存搜尋後的網頁內容，按搜尋日期組織
```

## 文件操作

### 搜索網址庫結構

```
搜索網址庫/
├── 白名單.md
├── 黑名單.md
└── 未分類.md
```

#### 白名單.md 格式

```markdown
# 白名單

## 添加時間 | 網址 | 添加原因 | 分類標籤

2026-05-05 19:30 | https://example.com/article1 | 用戶確認，內容優質 | 科技, AI
2026-05-05 19:35 | https://blog.example.org/post1 | 權威來源 | 學術
```

#### 黑名單.md 格式

```markdown
# 黑名單

## 添加時間 | 網址 | 屏蔽原因

2026-05-05 19:40 | https://spam.example.com | 內容質量低
2026-05-05 19:45 | https://ads.example.org | 廣告內容
```

#### 未分類.md 格式

```markdown
# 未分類

## 發現時間 | 網址 | 備註

2026-05-05 19:50 | https://new.example.com/article | 待用戶確認
```

### 未整理搜尋內容結構

```
未整理搜尋內容/
└── 2026-05-05/
    ├── 網頁標題1.md
    ├── 網頁標題2.md
    └── ...
```

#### 網頁內容文件格式

```markdown
# 網頁標題

- 網址：https://example.com/article
- 發布時間：2026-05-05
- 來源：來源網站名稱
- 狀態：待確認 / 自動通過
- 搜尋關鍵詞：AI, 機器學習
- 暫存時間：2026-05-05 19:30

## 內容摘要

這是一篇關於...的文章

## 完整內容

<article_content>
```

## 騰訊文檔 Skill 調用示例

### 搜索文檔

```
使用 tencent-docs skill 搜索「搜索網址庫」，查詢網址是否存在
```

### 創建文檔

```
使用 tencent-docs skill 創建文檔到「未整理搜尋內容」知識庫
文檔標題：網頁標題1
文檔內容：（完整的 Markdown 內容）
目標文件夾：2026-05-05
```

### 更新文檔

```
使用 tencent-docs skill 更新「搜索網址庫/白名單.md」
操作：在文件末尾添加新的白名單網址記錄
```

### 從知識庫刪除文檔

```
使用 tencent-docs skill 從「未整理搜尋內容」刪除已處理的文檔
文檔 ID：xxx
```

### 列出文件夾內容

```
使用 tencent-docs skill 列出「未整理搜尋內容/2026-05-05/」中的所有文檔
```

## 騰訊文檔特定功能

### 協作編輯

騰訊文檔支持多人協作編輯，適合團隊使用：

```
在創建「搜索網址庫」時，可以設置協作權限：
- 可編輯：團隊成員可以添加/修改網址
- 只讀：團隊成員只能查看網址庫
```

### 在線預覽

騰訊文檔支持在線預覽，方便查看暫存的網頁內容：

```
使用 tencent-docs skill 獲取文檔的在線預覽鏈接
文檔 ID：xxx
返回：預覽鏈接（可以直接在瀏覽器中打開）
```

### 版本歷史

騰訊文檔自動保存版本歷史，可以回滾到之前的版本：

```
如果誤刪了白名單中的網址，可以：
1. 使用 tencent-docs skill 查看文檔的版本歷史
2. 找到之前的版本
3. 恢復誤刪的內容
```

## 注意事項

1. **文件夾結構**：騰訊文檔使用文件夾來組織文檔，確保按日期組織文檔，便於管理和清理
2. **網址去重**：在添加前檢查網址是否已存在於白名單或黑名單
3. **定期維護**：建議每月清理一次「未整理搜尋內容」中的過期內容
4. **權限管理**：確保知識庫的訪問權限設置正確，避免敏感信息泄露
5. **API 限制**：騰訊文檔 API 可能有調用頻率限制，注意控制操作頻率
