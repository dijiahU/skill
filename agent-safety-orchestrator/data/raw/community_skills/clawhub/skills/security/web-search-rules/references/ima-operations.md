# IMA 知識庫操作參考

## 知識庫管理

### 檢查知識庫是否存在

使用 IMA skill 列出所有知識庫，檢查目標知識庫是否存在。

### 創建知識庫

如果知識庫不存在，使用 IMA skill 創建：

```
知識庫名稱：搜索網址庫
描述：記錄搜尋規則、網址的暫存名單（未分類白名單還是黑名單）、白名單和黑名單

知識庫名稱：未整理搜尋內容
描述：暫存搜尋後的網頁內容，按搜尋日期組織
```

## 文件操作

### 搜索網址庫結構

```
搜索網址庫/
├── 白名單.md
├── 黑名單.md
└── 未分類.md
```

#### 白名單.md 格式

```markdown
# 白名單

## 添加時間 | 網址 | 添加原因 | 分類標籤

2026-05-05 19:30 | https://example.com/article1 | 用戶確認，內容優質 | 科技, AI
2026-05-05 19:35 | https://blog.example.org/post1 | 權威來源 | 學術
```

#### 黑名單.md 格式

```markdown
# 黑名單

## 添加時間 | 網址 | 屏蔽原因

2026-05-05 19:40 | https://spam.example.com | 內容質量低
2026-05-05 19:45 | https://ads.example.org | 廣告內容
```

#### 未分類.md 格式

```markdown
# 未分類

## 發現時間 | 網址 | 備註

2026-05-05 19:50 | https://new.example.com/article | 待用戶確認
```

### 未整理搜尋內容結構

```
未整理搜尋內容/
└── 2026-05-05/
    ├── 網頁標題1.md
    ├── 網頁標題2.md
    └── ...
```

#### 網頁內容文件格式

```markdown
# 網頁標題

- 網址：https://example.com/article
- 發布時間：2026-05-05
- 來源：來源網站名稱
- 狀態：待確認 / 自動通過
- 搜尋關鍵詞：AI, 機器學習
- 暫存時間：2026-05-05 19:30

## 內容摘要

這是一篇關於...的文章

## 完整內容

<article_content>
```

## IMA Skill 調用示例

### 搜索知識庫

```
使用 IMA skill 搜索「搜索網址庫」，查詢網址是否存在
```

### 上傳文件到知識庫

```
使用 IMA skill 上傳文件到「未整理搜尋內容」知識庫
文件路徑：/tmp/search_result_1.md
目標文件夾：2026-05-05
```

### 從知識庫刪除文件

```
使用 IMA skill 從「未整理搜尋內容」刪除已處理的文件
文件ID：xxx
```

## 注意事項

1. **文件夾結構**：確保按日期組織文件，便於管理和清理
2. **網址去重**：在添加前檢查網址是否已存在於白名單或黑名單
3. **定期維護**：建議每月清理一次「未整理搜尋內容」中的過期內容
4. **權限管理**：確保知識庫的訪問權限設置正確，避免敏感信息泄露
