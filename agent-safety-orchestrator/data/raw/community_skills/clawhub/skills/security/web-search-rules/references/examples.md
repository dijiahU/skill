# Web Search Rules Skill 使用示例

## 示例 1：基本搜尋流程

### 用戶請求
```
請幫我搜尋關於「AI 代理」的微信公眾號文章，並保存到「科技」知識庫
```

### 執行流程

1. **檢查知識庫**
   - 檢查「搜索網址庫」是否存在 → 不存在，提示用戶創建
   - 檢查「未整理搜尋內容」是否存在 → 不存在，提示用戶創建

2. **用戶確認創建知識庫後**
   - 創建「搜索網址庫」知識庫，初始化白名單.md、黑名單.md、未分類.md
   - 創建「未整理搜尋內容」知識庫

3. **載入網址庫**
   - 讀取白名單.md → 獲得 5 個網址
   - 讀取黑名單.md → 獲得 3 個網址
   - 讀取未分類.md → 獲得 2 個網址

4. **執行搜尋**
   - 使用 `wechat-article-search` skill 搜尋「AI 代理」
   - 找到 10 篇文章

5. **過濾搜尋結果**
   - 文章 1：網址在白名單中 → 標記「自動通過」
   - 文章 2：網址在黑名單中 → 標記「自動過濾」，跳過
   - 文章 3-10：不在任何列表 → 標記「待確認」

6. **暫存內容**
   - 將文章 1、3-10 的內容保存到「未整理搜尋內容/2026-05-05/」

7. **諮詢用戶**
   ```
   找到 8 個新網址需要確認：
   
   1. [文章標題3](網址3)
      - 來源：微信公眾號 A
      - 摘要：介紹 AI 代理的基本概念...
   
   2. [文章標題4](網址4)
      - 來源：微信公眾號 B
      - 摘要：探討 AI 代理的應用場景...
   
   ...
   
   請問：
   - 哪些網址應該加入白名單？
   - 哪些網址應該加入黑名單？
   - 哪些文章的內容需要保存到「科技」知識庫？
   ```

8. **用戶回應**
   ```
   - 網址3、4、5 加入白名單
   - 網址6 加入黑名單
   - 網址3、4、5、7、8 的內容保存到「科技」知識庫
   ```

9. **更新網址庫**
   - 更新「搜索網址庫/白名單.md」，添加網址3、4、5
   - 更新「搜索網址庫/黑名單.md」，添加網址6

10. **整理並歸檔內容**
    - 從「未整理搜尋內容」讀取網址3、4、5、7、8 的內容
    - 整理格式，添加標籤
    - 保存到「科技」知識庫
    - 從「未整理搜尋內容」刪除這些文件

11. **生成報告**
    ```
    搜尋完成報告
    ====================
    
    搜尋關鍵詞：AI 代理
    搜尋時間：2026-05-05 20:15
    
    結果統計：
    - 總共找到：10 個結果
    - 白名單自動通過：1 個
    - 黑名單自動過濾：1 個
    - 用戶確認保存：5 個
    - 用戶放棄：3 個
    
    網址庫更新：
    - 新增白名單：3 個
    - 新增黑名單：1 個
    
    已保存內容位置：
    - 知識庫：科技
    - 文件數量：5 個
    ```

## 示例 2：規則建議

### 用戶請求
```
搜尋「區塊鏈技術」相關文章
```

### 執行流程

1. 完成搜尋和過濾
2. 暫存內容
3. 諮詢用戶

### 用戶確認模式

在用戶多次確認後，系統學習到規則：

```
根據您的歷史決策，系統建議以下規則：

1. 網域規則：所有來自 `区块链前沿` 公眾號的文章都應該加入白名單
2. 關鍵詞規則：標題包含「技術原理」的文章通常是有價值的
3. 來源規則：`科技日報` 發布的文章質量較高

是否要應用這些規則？
- 是：應用規則並自動分類類似內容
- 否：繼續手動確認
- 自定義：修改規則後應用
```

## 示例 3：批量操作

### 用戶請求
```
搜尋「投資理財」相關內容
```

### 執行結果

```
找到 20 個結果，其中：
- 15 個來自同一網域 (investment-news.com)
- 5 個來自其他來源

是否要：
1. 將所有來自 investment-news.com 的網頁加入白名單
2. 將所有來自 investment-news.com 的網頁加入黑名單
3. 逐個確認每個網頁
```

## 示例 4：定期維護

### 用戶請求
```
清理「未整理搜尋內容」中上個月的內容
```

### 執行流程

1. 列出「未整理搜尋內容」中上個月（2026-04）的文件夾
2. 顯示文件統計（數量、大小）
3. 詢問用戶是否要：
   - 刪除所有上個月的内容
   - 只刪除已處理的內容
   - 保留某些特定內容
   - 取消操作

## 注意事項

1. **首次使用**：確保在用戶首次使用時引導創建必要的知識庫
2. **用戶確認**：始終在用戶確認後再執行關鍵操作（更新網址庫、保存內容）
3. **錯誤處理**：如果 IMA 操作失敗，提供清晰的錯誤消息和建議解決方案
4. **性能考慮**：如果搜尋結果很多（>20），考慮分批處理或提供批量操作選項

## 示例 5：使用騰訊文檔作爲知識庫平台

### 用戶請求
```
請使用騰訊文檔作爲知識庫平台，幫我搜尋關於「機器學習」的微信公眾號文章，
並保存到「學術」知識庫
```

### 執行流程

1. **選擇平台**
   ```
   詢問用戶：「請問您想要使用哪個平台來管理搜尋規則和內容？」
   
   用戶選擇：「騰訊文檔」
   
   創建配置文件 `~/.workbuddy/skills/web-search-rules/config.json`：
   ```json
   {
     "platform": "tencent-docs",
     "search-url-library": "搜索網址庫",
     "unorganized-content": "未整理搜尋內容",
     "auto_create": true,
     "last_used": "2026-05-05 22:30:00"
   }
   ```
   
2. **檢查知識庫**
   - 使用 `tencent-docs` skill 檢查「搜索網址庫」是否存在 → 不存在，提示用戶創建
   - 使用 `tencent-docs` skill 檢查「未整理搜尋內容」是否存在 → 不存在，提示用戶創建
   
3. **用戶確認創建知識庫後**
   - 使用 `tencent-docs` skill 創建「搜索網址庫」知識庫
     - 創建文件「白名單.md」、「黑名單.md」、「未分類.md」
   - 使用 `tencent-docs` skill 創建「未整理搜尋內容」知識庫
   
4. **載入網址庫**
   - 使用 `tencent-docs` skill 讀取「白名單.md」→ 獲得 3 個網址
   - 使用 `tencent-docs` skill 讀取「黑名單.md」→ 獲得 2 個網址
   - 使用 `tencent-docs` skill 讀取「未分類.md」→ 獲得 1 個網址
   
5. **執行搜尋**
   - 使用 `wechat-article-search` skill 搜尋「機器學習」
   - 找到 8 篇文章
   
6. **過濾搜尋結果**
   - 文章 1：網址在白名單中 → 標記「自動通過」
   - 文章 2：網址在黑名單中 → 標記「自動過濾」，跳過
   - 文章 3-8：不在任何列表 → 標記「待確認」
   
7. **暫存內容**
   - 使用 `tencent-docs` skill 創建文件到「未整理搜尋內容/2026-05-05/」
   - 將文章 1、3-8 的內容保存為 Markdown 文件
   
8. **諮詢用戶**
   ```
   找到 6 個新網址需要確認：
   
   1. [文章標題3](網址3)
      - 來源：微信公眾號 C
      - 摘要：介紹機器學習的基本概念...
   
   2. [文章標題4](網址4)
      - 來源：微信公眾號 D
      - 摘要：探討機器學習的應用場景...
   
   ...
   
   請問：
   - 哪些網址應該加入白名單？
   - 哪些網址應該加入黑名單？
   - 哪些文章的內容需要保存到「學術」知識庫？
   ```
   
9. **用戶回應**
   ```

   - 網址6 加入黑名單
   - 網址3、4、5、7 的內容保存到「學術」知識庫

12. **生成報告**

## 示例 6：平台切換

### 用戶請求
```
我想要從 IMA 知識庫切換到騰訊文檔
```

### 執行流程

1. **確認切換**
   ```
   詢問用戶：「您確定要從 IMA 知識庫切換到騰訊文檔嗎？」
   
   注意：切換平台可能需要手動遷移數據。
   ```
   
2. **用戶確認後**
   ```
   提供選項：
   1. 遷移現有的網址庫和暫存內容
   2. 不遷移數據，重新開始
   
   用戶選擇：「遷移現有的網址庫和暫存內容」
   ```
   
3. **導出 IMA 數據**
   - 使用 IMA skill 導出「搜索網址庫」中的白名單、黑名單、未分類數據
   - 使用 IMA skill 導出「未整理搜尋內容」中的網頁內容
   
4. **導入騰訊文檔**
   - 使用 `tencent-docs` skill 創建「搜索網址庫」知識庫
   - 使用 `tencent-docs` skill 創建「白名單.md」、「黑名單.md」、「未分類.md」
   - 將導出的數據導入到這些文件
   - 使用 `tencent-docs` skill 創建「未整理搜尋內容」知識庫
   - 將導出的網頁內容導入
   
5. **更新配置**
   - 更新 `config.json` 中的 `platform` 字段為 `tencent-docs`
   - 更新 `search-url-library` 和 `unorganized-content` 字段
   
6. **完成切換**
   ```
   平台切換完成！
   
   原平台：IMA 知識庫
   新平台：騰訊文檔
   
   遷移的數據：
   - 白名單：5 個網址
   - 黑名單：3 個網址
   - 未分類：2 個網址
   - 暫存內容：8 個網頁
   
   後續的搜尋操作將使用騰訊文檔作爲知識庫平台。
   ```

## 平台功能對比參考

在幫助用戶選擇平台時，可以參考 `references/platform-comparison.md` 中的詳細對比表。

**快速建議**：

- 選擇 **IMA 知識庫**，如果：
  - 需要 AI 搜索和智能推薦
  - 主要存儲文本內容
  - 個人使用

- 選擇 **騰訊文檔**，如果：
  - 需要多人協作編輯
  - 需要豐富的格式支持
  - 需要強權限管理
