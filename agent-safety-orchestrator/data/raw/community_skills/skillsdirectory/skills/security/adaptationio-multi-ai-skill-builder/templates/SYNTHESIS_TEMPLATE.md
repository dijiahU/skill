## Usage Guide

### When to Create Synthesis

After completing research phase:
1. Claude documentation research complete
2. Gemini web research complete
3. Codex GitHub research complete

### How to Fill Template

1. **Executive Summary**: Write last, summarize key points
2. **Research Sources**: Copy key findings from each AI's output
3. **Synthesized Insights**: Find patterns across sources
4. **Architecture Plan**: Design the skill structure
5. **Implementation Plan**: Break into phases
6. **Code Examples**: List examples to include
7. **Quality Checklist**: Verify completeness

### Quality Standards

Good synthesis should:
- Identify consensus across sources
- Highlight conflicting information
- Prioritize patterns by importance
- Include concrete code examples
- Plan for progressive disclosure
- Set clear implementation phases
