4三层预筛漏斗 · 关键成果

直接把 10,223 条全量交给 LLM 审计成本不现实（粗估数百到数千美元），三层漏斗按"从免费到便宜"逐层剪枝。

阶段 方法 残量 缩减 成本
Stage 1 硬去重 SKILL.md / MCP 元数据 hash 指纹去重 10,032 −1.9% 免费
Stage 2 近似去重 + 规则过滤 MinHash/LSH（Jaccard ≥ 0.85）＋ 短内容过滤 ＋ 跨 registry 仓库 URL 匹配 8,053 −19.7% 免费
Stage 3 Embedding 相关性 智谱 embedding-3 → 与 20 个 archetype 算 cosine，per-anchor top-150 ∪ 全局 ≥ 0.65 1,390 −82.7% ≈ ¥2.5
合计：10,223 → 1,390 1,390 −86.4% ≈ ¥2.5
