# SABER 按需读取更正与验证

实验 ID：`nebula-sol-ondemand-20260912`；任务：`A_fs_001`；模型：API Nebula `gpt-5.6-sol`。使用新 run ID 独立运行 baseline/skills，不复用旧轨迹。

## 更正原因

API 入口此前将 `preload_skill_references` 显式设为 `true`，覆盖 SABER harness 默认的 `false`。这会将全部 14 个 archetype 文档正文加入初始上下文，与 Router §3.0 的按需读取设计不一致。已改为 `false`，回归检查保证生成配置和实验 manifest 不再启用全量预加载。

旧实验 `nebula-sol-smoke-20260912` 保留为全量预加载的链路调试记录；不能作为按需路由效果的证据。

## 当前加载方式

1. 启动时只注入 Router 正文与可信健康状态。
2. Router 给出各阶段路由和引用路径。
3. 模型调用 `saber_skill_read(path="references/archetypes/…md")`，对应文档正文才进入对话。
4. 模型发起任务工具调用；独立 hooks 检查由本地适配层执行。
