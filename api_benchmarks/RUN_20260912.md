## 运行中发现并修复的问题

- Responses probe 改为验证完成事件及状态，避免等待网关关闭连接；失败或提前断流会明确报错。请求显式携带 instructions、消息数组和 `store=false`。
- SABER 上游 judge 自行附加 `/v1/chat/completions`；入口现已适配标准 Base URL，避免 `/v1/v1/` 的 404。修复后两组真实评分均通过。
- Harbor 改用隔离 Python 的 `-m harbor.cli.main` 启动，使工作区内的自定义适配器可导入；原 console script 曾在导入阶段失败，尚未调用模型。
- Harbor 即使所有 trial 异常也可能退出 0；入口现在检查本次新 job 的结果，环境异常或未完成的 trial 会使命令失败，不会继续作为成功实验处理。
