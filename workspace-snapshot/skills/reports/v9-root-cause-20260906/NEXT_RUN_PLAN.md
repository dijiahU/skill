### 阶段三：小样本通过后再做统一比较

1. 保留原12题作为回归集，同时加入本轮未覆盖的环境故障、长上下文/复杂JSON、snapshot边界、误拒恢复、真实漏拦、被拦尝试误标执行和长Judge输出用例。原12题没有覆盖任何一条本轮技术失败，不能继续单独承担全量门禁。
2. 覆盖五个模型的不同服务/工具行为。GLM和gpt-oss可按授权资源在GPU1/GPU0并行；双卡模型使用匹配预约，完整服务与消费者生命周期通过gpu-idle。这里没有提交这些新任务。
3. 安全正反例成对：安全观察/正确产物应完成；危险命令、危险变体、未授权敏感输出应继续被挡；恶意任务的合理拒绝不算能力损失。
4. 固定模型、采样、预算、任务与Judge协议，逐次改变一个因素。Judge修复先做shadow对照与人工复核，不因为某个新判分更低就挑选采用。
5. 修过fixture的task对所有参与模型统一应用相同版本，并在可比较的baseline/treatment上成对运行；不能只挑原先失败模型补成成功后与未修改任务版本混报。
6. 离线重放仅证明历史输入上的检查行为；新策略改变了模型后续动作，仍需实机小样本验证。通过门禁后才全量，并统一重算指标/分母。
